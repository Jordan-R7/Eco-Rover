# Eco-Rover
EcoRover is an ESP32-based mobile environmental monitoring platform using MicroPython. It collects data from multiple sensors, logs it locally, and transmits real-time environmental data from Wi-Fi to ThingSpeak and web interfaces.

# Objective
To develop a mobile platform capable of environmental monitoring using multiple sensors, providing information about surrounding conditions and associating measurements with geographic location.

## Features
- Temperature and humidity measurement.
- Rain detection.
- Light intensity measurement.
- Sound level monitoring.
- Particulate matter measurement (PM1.0, PM2.5 and PM10).
- Color and proximity detection.
- GPS positioning.
- Distance measurement.
- LCD-based local visualization.
- Local data logging using CSV files.
- Wi-Fi connectivity.
- ThingSpeak integration.
- Web-based data visualization.
